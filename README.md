# ⚽ MatchPulse

## AI-Powered Football Intelligence Platform

MatchPulse transforms synthetic football match events into real-time insights, explainable narratives, personalized fan experiences, broadcast-ready studio insights, and automated match recaps.

Built for the Microsoft Premier League Hackathon, MatchPulse helps fans, analysts, and broadcasters understand not only what happened during a match, but also why it happened.

---

# 🚀 Problem Statement

Football fans often receive raw statistics such as goals, shots, and possession percentages but lack meaningful context and storytelling around those events.

Analysts and broadcasters require intelligent systems that can transform football event streams into actionable insights, engaging narratives, and personalized experiences.

---

# ✅ Solution

MatchPulse uses a Multi-Agent AI Architecture to transform synthetic football events into:

- Real-Time Match Intelligence
- AI-Generated Match Narratives
- Explainable Insights
- Personalized User Experiences
- Broadcast Studio Recommendations
- Automated Match Recaps

---

# 🏗️ Multi-Agent Architecture

```text
Synthetic Match Events
            │
            ▼
      Event Agent
            │
            ▼
      Stats Agent
            │
            ▼
 Gemini Narrative Agent
            │
            ▼
Gemini Explainability Agent
            │
            ▼
 Personalization Agent
            │
            ▼
   Gemini Recap Agent
            │
            ▼
      Streamlit UI
```

---

# 🤖 Agent Responsibilities

### Event Agent
- Loads and validates football event data.
- Creates the live match event stream.

### Stats Agent
Calculates:
- Possession %
- Pass Accuracy %
- Goals
- Shots
- Tackles
- Pressure Index

### Gemini Narrative Agent
Generates AI-powered football storytelling based on match statistics.

### Gemini Explainability Agent
Explains why important events occurred and how they impacted the game.

### Personalization Agent
Provides:
- Analyst View
- Fan View
- Player View
- Studio View

### Gemini Recap Agent
Creates automated full-time match summaries.

# ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/abhigoud0008/Matchpulse.git
```

Navigate to the project:

```bash
cd Matchpulse
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Update your Gemini API key in config.py.

Run the application:

```bash
python -m streamlit run app.py
```
